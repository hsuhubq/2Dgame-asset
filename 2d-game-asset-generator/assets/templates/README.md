# 素材模板

这个文件夹用于存放示例模板素材。

## 建议添加的模板

### 角色模板
- `character_template_32x32.png` - 32×32角色模板
- `character_template_64x64.png` - 64×64角色模板

### 地图瓦片模板
- `tileset_template_16x16.png` - 16×16瓦片模板
- `tileset_template_32x32.png` - 32×32瓦片模板

### UI模板
- `button_template.png` - 按钮模板
- `panel_template.png` - 面板模板
- `healthbar_template.png` - 血条模板

### 图标模板
- `icon_template_16x16.png` - 16×16图标模板
- `icon_template_32x32.png` - 32×32图标模板

## 使用方法

这些模板可以作为参考，帮助用户理解：
1. 正确的尺寸比例
2. 透明背景的使用
3. 像素艺术的轮廓风格
4. 光照方向的一致性

用户可以基于这些模板生成自己的素材。
